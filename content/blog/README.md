# Blog Content

Add blog posts in `content/blog/posts.json`.

Each post supports:

- `slug`: URL path after `/blog/`
- `title`: visible article title
- `seoTitle`: custom browser/search title
- `seoDescription`: custom meta description
- `excerpt`: short summary shown on `/blog`
- `keywords`: SEO keywords array
- `author`: article author/publisher name
- `coverImage`: optional image URL
- `publishedAt`: ISO date
- `updatedAt`: optional ISO date
- `bodyMd`: article body in Markdown
