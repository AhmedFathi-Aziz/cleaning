# الأخبار الوطنية (ملفات ثابتة)

كل خبر في **ملف JSON منفصل**. اسم الملف (بدون `.json`) يصبح رابط الصفحة:

`/news/اسم-الملف`

## إضافة خبر جديد

1. أنشئ ملفاً في `content/national-news/articles/`، مثلاً:
   `summer-pest-tips-2026.json`

2. املأ الحقول (لا حاجة لحقل `slug` — يُؤخذ من اسم الملف):

```json
{
  "title": "عنوان الخبر",
  "excerpt": "جملتان تظهران في القائمة والبطاقات",
  "bodyMd": "## عنوان فرعي\n\nنص الخبر بصيغة Markdown.",
  "sourceUrl": "https://www.example.gov.sa",
  "sourceLabel": "اسم الجهة أو المصدر",
  "seoTitle": "عنوان SEO (اختياري)",
  "seoDescription": "وصف SEO (اختياري)",
  "keywords": ["كلمة1", "كلمة2"],
  "publishedAt": "2026-05-22T10:00:00.000Z",
  "updatedAt": "2026-05-22T10:00:00.000Z"
}
```

3. احفظ الملف ثم شغّل (يُحدّث الملف المضمّن في الحزمة تلقائياً):

   ```bash
   npm run news:sync
   ```

   أو أعد `npm run dev` / `npm run build` (الـ prebuild يشغّل sync تلقائياً).

4. راجع محلياً: `http://localhost:3000/news/summer-pest-tips-2026`

5. للنشر على Cloudflare: `npm run deploy` (أوقف `npm run dev` أولاً على Windows).

## قواعد مهمة

- **اسم الملف**: أحرف لاتينية صغيرة، أرقام، وشرطات فقط (`a-z`, `0-9`, `-`).
- **`sourceUrl`**: إلزامي — رابط http أو https للمصدر الرسمي.
- **`bodyMd`**: المحتوى الكامل للصفحة (Markdown).
- على الرئيسية تُعرض **أحدث 4 أخبار**؛ الباقي في `/news`.

## مثال جاهز

انسخ `_example.json` وأعد تسميته بعد التعديل (احذف الشرطة السفلية في البداية `_` من الاسم إن أردت نشره — الملفات التي تبدأ بـ `_` لا تُحمَّل).
